# Primitive Matrix Ontology v0.1

## Purpose

This document answers the first three creator-style design questions as far as the current mathematics allows:

1. What is the primitive state?
2. What is physically real versus bookkeeping?
3. Is the 108-state core global or repeated?

The result is intentionally conservative. Exact canonical structure is separated from physical hypotheses.

## 1. Exact reduction of the 108-state core

The canonical polarity operator is

$$
P=T_{54}.
$$

Because

$$
108=2\times54,
$$

every core state has a unique representation

$$
\boxed{
n=a+54p
}
$$

with

$$
a\in\{0,\ldots,53\},
\qquad
p\in\{0,1\}.
$$

Here:

- $a$ is the antipodal-pair index;
- $p$ is the polarity branch.

Under the exact canonical polarity operation,

$$
P(n)=n+54\pmod{108},
$$

the decomposition becomes

$$
\boxed{
(a,p)\longrightarrow(a,1-p).
}
$$

Therefore the pair index is invariant under polarity and the polarity bit flips.

This is an exact finite result.

## 2. Consequence: do not double-count canonical polarity

Earlier candidate state descriptions often used both a core state $n$ and a separate polarity variable $\sigma$.

If $\sigma$ is intended to mean exactly the canonical antipodal polarity generated by $T_{54}$, then $n$ and $\sigma$ are not independent.

The canonical address already contains that bit.

This does not prohibit additional physical polarity-like fields, but any such field must be defined as something distinct from the exact $T_{54}$ branch.

## 3. Current minimal exact address

The exact local finite address is therefore

$$
\boxed{
\text{CoreAddress}=(a,p),
}
$$

where

$$
a\in\mathbb Z_{54}
$$

as a label set and

$$
p\in\mathbb Z_2
$$

as a branch bit.

This is a coordinate decomposition of the 108 labels. It should not be interpreted as a claim that

$$
\mathbb Z_{108}\cong\mathbb Z_{54}\times\mathbb Z_2
$$

as groups.

Indeed, since $54$ and $2$ are not coprime, that group-product statement would be false.

The decomposition is a bijection of the finite state set adapted to the canonical polarity involution.

## 4. Candidate dynamical cell state

The current minimal candidate dynamical state is represented as

$$
\boxed{
X_{\rm cell}
=
(a,p,\ell,\phi,\Pi_\phi).
}
$$

Only

$$
(a,p)
$$

is exact canonical structure.

The remaining fields are explicit hypotheses:

- $\ell$: scale level;
- $\phi$: local phase;
- $\Pi_\phi$: conjugate phase momentum.

Their inclusion is motivated by the existing nested-scale and Hamiltonian dynamics, but their status as fundamental physical variables has not been derived.

## 5. What should not be primitive if the unification program succeeds

The current ontology ledger classifies the following as quantities that should preferably emerge rather than be inserted as primitive local labels:

- particle species;
- rest mass;
- electric charge;
- spacetime curvature;
- entropy;
- macroscopic temperature.

This is not yet a proof that they emerge. It is a design constraint.

If they must be entered independently at every cell, the theory explains less.

## 6. Gauge variables belong on links

Gauge connection variables are naturally associated with oriented links between cells.

For an Abelian example,

$$
U_{xy}=e^{i\theta_{xy}}.
$$

For a non-Abelian group,

$$
U_{xy}\in G.
$$

Their conjugate electric fields also live naturally on links.

This is important because a gauge potential is not an additional independent scalar property of a site. Gauge transformations act locally on frames while link variables transform between neighboring frames.

The ontology therefore classifies:

- gauge link: candidate edge degree of freedom;
- electric field: candidate edge conjugate degree of freedom;
- gauge choice: redundancy rather than physical observable.

## 7. Six boundary gates as connectivity

The canonical boundary labels

$$
B_6
=
\{+X,-X,+Y,-Y,+Z,-Z\}
$$

are now treated, at the ontology layer, primarily as oriented connectivity labels.

The current repeated-cell candidate uses them as the six nearest-neighbor directions of a dimensionless three-coordinate cell complex.

This yields the adjacency structure

$$
(x,y,z)
\leftrightarrow
(x\pm1,y,z),
$$

$$
(x,y,z)
\leftrightarrow
(x,y\pm1,z),
$$

$$
(x,y,z)
\leftrightarrow
(x,y,z\pm1).
$$

This is a candidate locality adapter.

It is not a theorem that physical space must be this lattice.

## 8. Repeated versus global core

A single global 108-state cycle by itself does not provide enough independent local degrees of freedom to represent an extended many-body world in the ordinary sense.

The existing open-field engine already uses many spatial cells.

The ontology therefore formalizes the current working hypothesis:

$$
\boxed{
\text{one spatial site carries one local Matrix cell state.}
}
$$

Many such cells are connected by the six oriented gates.

This is now explicit rather than implicit.

The alternative hypothesis, that the entire universe is one global 108-state system whose apparent locality emerges some other way, remains logically possible but is not the architecture implemented by the present local field solvers.

## 9. No physical length has been assigned

The repeated cell complex uses dimensionless coordinates.

It does not contain a physical lattice spacing $a_{\rm phys}$.

Therefore this ontology work does not solve the dimensional-scale problem.

The mapping

$$
(x,y,z)\mapsto
(a_{\rm phys}x,a_{\rm phys}y,a_{\rm phys}z)
$$

remains undefined until a physical scale is derived or independently calibrated.

This separation is deliberate.

## 11. Answer to creator-style Question 1

If constructing the model from the smallest current set of assumptions, do not begin with every quantity used by every later subsystem.

Begin with the least structure already forced by the canonical mathematics.

The exact discrete local address is

$$
\boxed{
(a,p).
}
$$

Then add only dynamical variables that cannot be derived from it.

At present the minimal candidate extension is

$$
\boxed{
(a,p,\ell,\phi,\Pi_\phi),
}
$$

with gauge information placed on links.

This is a cleaner ontology than

$$
(n,\sigma,\phi,A,\ldots)
$$

when $\sigma$ merely duplicates the polarity already encoded by $n$.

## 13. Answer to Question 3

The current engine architecture adopts the repeated-cell hypothesis:

$$
\boxed{
\text{many local Matrix cells}
+
\text{six-gate adjacency}.
}
$$

This is the topology used by the present local field engines.

What remains open is not whether the current software is repeated. It is whether nature actually uses this repeated-cell architecture and what physical scale and continuum limit it possesses.
