# Isolated recursive pair dynamics

The tangent scale-impedance audit shows that every tested 1:2 recursive interface is locally
self-similar. The remaining question is whether that self-similarity persists in finite-time
dynamics or whether the low child-work uptake is already generated by one isolated interface.

This checkpoint isolates one parent-child pair at parent scales 1, 1/2 and 1/4.

## Corresponding dynamic initial conditions

Every pair begins with the same dimensionless parent displacement used by the recursive tree,
while the child begins at the material reference state. Generalized rates are scaled inversely
with parent length. Physical timestep and duration are scaled linearly with parent length.

Thus each run represents the same dimensionless experiment at a different recursive scale.

At matched reference times the audit compares:

- generalized coordinates;
- parent-scale-normalized rates;
- mechanical energy divided by parent scale cubed;
- damping loss divided by parent scale cubed;
- connector potential divided by parent scale cubed;
- endpoint work divided by parent scale cubed;
- child-work uptake relative to parent-work magnitude.

If the implemented local dynamics are genuinely self-similar, these normalized trajectories
must coincide across all three interfaces.

## Why this is separate from the full tree

A two-module pair does not reproduce binary fan-out, upstream forcing or loading from additional
levels. Its child-work fraction therefore is not assumed to equal the 2–3% measured inside the
full depth-three tree.

If isolated pair dynamics are scale invariant but differ from embedded-tree uptake, the remaining
attenuation belongs to cascade loading, phase and propagation rather than a broken local scale law.

This checkpoint does not add a coupling, validate a spatial recursive embedding, establish
arbitrary depth, or map the material dynamics onto the 69-component toroidal assembly.
