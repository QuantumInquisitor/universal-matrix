## A static spatial comparison is possible without inventing physics

Available coordinates are sufficient for a **finite geometric descriptor**, not yet a physical scattering calculation:

- `src/lynchpin_finite_panel_control.py::panel_vertices` supplies original finite-panel coordinates with declared dimension/phase; `tests/test_lynchpin_finite_panel_control.py` validates geometry/clearance, not crystallinity.
- `scripts/export_fold_material_viewer_frames.py::adapt` exports `vertices_m` from computed 22-owner material geometry; `tests/test_fold_material_viewer_frames.py` validates that contract. The accepted example at `docs/docs/material-viewer-example.json` is a usable fixed snapshot. Its module coordinates are local frames: select one module rather than overlapping them at an invented common origin.
- `src/toroidal_assembly_breathing.py` and the aperture assembly reports describe a different finite/common-scaling flow geometry. Its domains are not interchangeable with the material vertices. No new 22-to-69 mapping follows from comparing their point patterns.

First proposed dataset: choose one named module and the first saved physical-time frame from the accepted material example. Preserve body/vertex IDs and coordinate units. Compare (a) all vertex occurrences weighted by ownership and (b) a documented unique-coordinate set separately; duplicate vertices change weights and cannot be silently discarded. Use exact stored-coordinate identity for the initial deduplication rule, and report near-coincident points instead of inventing a physical merge tolerance. A body-center population, if selected later, is a different observable. Material-mass weights require a justified mass/quadrature population; vertex count is not mass.

For equal unit scatterers compute the finite geometric descriptor

`S(k) = |sum_j exp(i k dot r_j)|^2 / N`,

with `k` in radians/metre for metre coordinates. Weighted descriptors must state weights and normalization separately. This does not assign atomic form factors, wavelength, coherent illumination or detector response. Retain the zero-vector value `S(0)=N` as a normalization control and exclude that trivial peak from any ordering interpretation. Report pair-distance distribution and directional structure-factor cuts; radial averaging can hide anisotropy, so it cannot be the only result.

Necessary independent checks: permutation and rigid-translation invariance; reciprocal-vector rotation covariance; real/nonnegative output and `S(-k)=S(k)`; direct pair-sum identity `S(k)=1+(2/N)sum_(i<j) cos(k dot (r_i-r_j))`; and common-scale identity `S_(s r)(k)=S_r(s k)`. These test the statistic independently of the specimen.

Controls, chosen before evaluation:

1. A finite periodic cubic point set with explicit lattice spacing/window, checked at known reciprocal-lattice vectors.
2. An explicitly defined finite cut-and-project quasiperiodic reference with documented generator/window. This reference needs its own construction validation; do not assign the label to an arbitrary projected 13-vector dataset.
3. A seeded randomized point set matched in count/window and a jittered copy of the specimen. Report excluded-volume constraints, if any, since these alter pair correlations. Preserve exact realizations and use an ensemble before making a chance-probability statement.

The initial one-module comparison may report finite-pattern similarities/differences only. Before any crystal/quasicrystal conclusion, specify several independently justified larger coordinate populations at controlled density and boundary window; compare peak positions/intensities/widths and correlations across both size and recursion depth. A finite recursion with repeated scale changes is not a fixed-density thermodynamic sequence. If no valid sequence is available, explicitly retain the finite descriptor and leave bulk ordering unresolved.

A claimed nontrivial peak is numerically unsupported if it is the forward peak, disappears under a refined reciprocal-space grid, tracks duplicate-count changes without the declared weighting, or is comparable to matched randomized realizations under the predeclared statistic. A declared long-range-order conclusion is unsupported without the stated size/correlation controls. These are interpretation/rejection gates; no numerical spatial-order threshold or positive result is fabricated here.

## Concrete next comparisons and required inputs

1. **Low-cost static geometry:** implement and independently test the descriptor on one accepted module and simple periodic/random controls, then add a separately verified quasiperiodic reference. This requires explicit point/weight/window choices, not new material parameters. Keep finite-pattern conclusions bounded.
2. **Broader wave physics:** extend the periodic field basis to paired sine/cosine modes and additional wavelength families, preserving the existing quartic potential normalization. Compare truncation, temporal and quadrature errors separately. A finite-boundary variant needs its own operator/flux contract first.
3. **Stochastic controls:** a separate synthetic measurement-noise study may use saved finite-band Gaussian coefficients and common paths across refinement; the already-completed actuator/delay controls remain baselines. Physical application requires sensor spectra/correlation and actuator calibration.
4. **Timing usefulness:** specify one realistic acquisition/readout backend and match its assumptions to the ordinary comparator before another large spin sweep. If those inputs are unavailable, retain the existing no-demonstrated-advantage outcome.

Required physical inputs remain material wave speed/dispersion and damping, finite geometry/support boundaries, coupling/flux laws, calibrated coordinate/time scales and attachment frames, sensor/actuator characteristics, and timing readout/energy models. None can be inferred solely from attractive geometry, the number 13, a repeated oscillation or an unverified image/reel.

The matrix closes a requirements-mapping gap, not P05/P06. Each implementation should be a separate bounded proposal with frozen observables, controls, numerical reproduction gates and stated physical assumptions. No existing result, original criterion or task status is replaced.
