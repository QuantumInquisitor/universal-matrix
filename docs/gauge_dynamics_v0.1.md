# Gauge Dynamics Extension v0.1

## Purpose

This extension adds a compact U(1) lattice-gauge field on a routing-by-scale cylinder built from Universal Matrix structures.

It is not part of Canonical Kernel v0.4. It is an experimental physical bridge intended to test whether the Matrix phase architecture can support a mathematically clean electromagnetic-like gauge sector.

## 7. Exact tests now implemented

The test suite checks:

1. the 36 gauge sites correspond exactly to the canonical (T_{21}) routing orbit;
2. local gauge transformations preserve every plaquette;
3. local gauge transformations preserve the Wilson action;
4. local gauge transformations preserve full routing holonomy;
5. pure-gauge connections have zero plaquette curvature;
6. pure-gauge connections have zero Wilson action and zero field-equation residual;
7. the gauge-covariant matter phase is invariant;
8. analytic action gradients agree with finite-difference derivatives;
9. the compact action converges to its quadratic weak-field form for small field angles.

## 8. Relation to electromagnetism

This extension establishes a genuine U(1) gauge structure. It does not yet establish physical electromagnetism.

To obtain a Maxwell interpretation we still need to specify which lattice directions correspond to time and space, or otherwise define a Hamiltonian/evolution law.

The present ((ell,k)) lattice is a scale-by-routing cylinder, not an assumed spacetime lattice. Therefore the plaquette (F_{ell,k}) should presently be called **gauge curvature** rather than electric or magnetic field.

A physical electromagnetic identification requires at least:

- a physical interpretation of the two lattice directions;
- a dimensional map for the gauge connection;
- source/current variables;
- a dynamical time coordinate or Hamiltonian;
- comparison with Maxwell observables.
