# Material forces with finite reserves and a coupled pair

The explicit material potential now propagates through the existing finite-reserve
module and two-module connector. Select `potential="constitutive"`; default calls
still use the historical quadratic law. Force evaluation and every mechanical
energy measurement use the same selected law.

Each module owns kinetic and material energy and one finite reserve. The connector
owns one generalized spring energy. Delivered actuator work and connection work
are transfers, not additional stored energy. Damping, conversion inefficiency and
reserve leakage remain separately accumulated losses. The root account is the
sum of module mechanical energies, remaining reserves, connector energy and all
losses. There is no external replenishment in this checkpoint.

The reporter compares fueled, conservative and disconnected pairs at 0.02- and
0.01-second steps over 0.4 seconds. It also compares the disconnected first module
against the single-reservoir model, runs an empty-reserve control, and deliberately
breaks connector reaction and reservoir debit to test whether the accounts detect
unphysical energy creation.

```sh
uv run python scripts/report_fold_material_coupling.py --output artifacts/fold-material-coupling/report.json
uv run python -m pytest tests/test_fold_material_coupling.py tests/test_fold_reservoir.py tests/test_fold_coupling.py
```

This uses two equal-size reduced specimens and a synthetic generalized connector.
It does not validate a spatial joint, collision/contact, a whole-structure recursive
material model, the separate 69-domain flow assembly or XR. Larger and differently
scaled networks continue using their historical defaults until the material energy
scaling and ownership are explicitly integrated and checked.

## Validation

43 reservoir/pair tests pass, including 12 new constitutive tests. A further 57
network/mapped/active-multiscale tests pass with their historical defaults.
At dt=0.01 s, total residuals are 8.01e-15 J for the fueled pair,
4.03e-15 J for the conservative pair and 5.85e-15 J when disconnected.
The disconnected module's final state matches its single counterpart exactly.
Wrong reaction produces 1.32e-7 J imbalance; omitted reserve debit produces
5.38e-7 J. These are intentionally broken controls, not engine output claims.

## Historical restart compatibility

The preceding material-dynamics change caused the older stability workflow to
reject its saved seed because one shared source file changed. The exact seed and
its historical hashes are retained. `fold-seed-compatibility.json` pins the three
reviewed source transitions and exact historical snapshots. The loader records
historical and current provenance separately, rejects unknown changes, and the
26 passing stability tests include snapshot/manifest tampering and comparison
against historical defaults. This is bounded regression evidence; it does not
relabel the saved seed as generated by new code or change its quadratic model.
