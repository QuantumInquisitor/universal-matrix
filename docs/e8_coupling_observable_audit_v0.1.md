# E8 Coupling Observable Audit v0.1

## Result

The first scalar-coupling candidate is algebraically compatible with the
existing gauge sectors, but it does not yet produce distinct E8 dynamics.

The reason is structural.

If the E8 Cartan state is restricted to the 240-root orbit, every root has the
same quadratic norm.

Therefore

||h||^2 = constant

on the entire orbit.

A Weyl-invariant scalar built only from that quadratic norm cannot distinguish
which root orientation is present.

## Consequences for candidate observables

### U(1), SU(2), and SU(3) matter norms

A term of the form

g ||h||^2 Psi^dagger Psi

has the same field dependence as an existing mass term when ||h||^2 is fixed.

It therefore behaves as a mass-parameter shift, not a new E8 signature.

### Gauge energy density

A term of the form

g ||h||^2 F^2

or its lattice Wilson-energy analogue merely rescales the corresponding gauge
coupling when ||h||^2 is fixed.

### Neutral reciprocity or content scalar

A linear coupling

g ||h||^2 chi

acts as a constant source or offset on a fixed root orbit.

## No preferred scalar selected

None of the immediately available gauge-invariant scalars is promoted as the
preferred physical E8 coupling.

Doing so would confuse parameter renormalization with a new prediction.

## What would be required for distinct E8 dynamics

At least one of the following must be added and independently justified:

1. a variable radial/amplitude degree of freedom for the E8 Cartan state;
2. a second object that transforms covariantly under the E8 Weyl action so an
   orientation-sensitive invariant can be formed;
3. a larger full E8 representation, which would introduce many new degrees of
   freedom and therefore requires a separate physical motivation.

The first option is the smallest extension, but it is still a genuinely new
state variable and cannot be treated as already present.

## Mathematical context

The E8 Weyl group acts on the rank-eight root space by reflections. Polynomial
Weyl invariants are constant on each Weyl orbit. For the root orbit, the
quadratic invariant is already fixed by equal root length. Higher invariants
can distinguish different generic Cartan points, but not members of a single
Weyl orbit.
