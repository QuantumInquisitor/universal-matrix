# Unified Gauge Engine v0.2

## Purpose

The unified engine now uses a true open cubical gauge complex by default. The six canonical gates act as physical boundary faces rather than as a periodic zero-mode workaround.

Implementation:

`src/unified_engine.py`

Primary open-field dynamics:

`src/open_gauge_dynamics.py`

Open Gauss solve:

`src/open_boundary_solver.py`

Open polarity source map:

`src/open_polarity_sources.py`

## 1. Default open architecture

The spatial complex has no wraparound links.

Open link arrays are

$
A_x:(n_x-1,n_y,n_z),
$

$
A_y:(n_x,n_y-1,n_z),
$

$
A_z:(n_x,n_y,n_z-1).
$

The six physical boundary faces correspond to

$
\{+X,-X,+Y,-Y,+Z,-Z\}.
$

## 2. Discrete exterior calculus

The open gauge sector uses the cochain sequence

$
C^0\xrightarrow{d_0}C^1\xrightarrow{d_1}C^2
$

with the exact algebraic identity

$
\boxed{d_1d_0=0}.
$

This guarantees that a pure gradient has zero lattice curl.

The magnetic force is generated by

$
-\beta d_1^\ast d_1A.
$

Because

$
d_1d_0=0,
$

the adjoint structure implies its divergence vanishes, providing the discrete source-free compatibility required by Gauss evolution.

Independent numerical scratch checks gave machine-precision residuals of approximately:

- curl(gradient): $4.4\times10^{-16}$
- curl-adjoint identity: $7.1\times10^{-15}$
- divergence of magnetic force: $3.6\times10^{-15}$

These checks validate the operator algebra independently of the repository test runner.

## 3. Open electric Gauss law

The full source is

$
\rho_E=\rho_{\rm pol}+\rho_{\rm free}.
$

No mean subtraction is used in open mode.

The finite-volume Gauss equation is

$
\boxed{
\nabla_{\rm open}\cdot E+b_{\partial V}=\rho_E
}
$

where $b_{\partial V}$ is the six-face outward electric flux contribution.

Global compatibility is the discrete divergence theorem:

$
\boxed{
\sum_x\rho_E(x)
=
\sum_{g\in B_6}\Phi_g^{E,\rm outward}.
}
$

Therefore nonzero enclosed electric charge is supported directly.

## 4. Open source evolution

Polarization uses an open finite-volume divergence rather than the old periodic operator.

For cell-centered polarization $P$,

$
\rho_{\rm pol}
=
-\nabla_{\rm FV}\cdot P.
$

Its current is

$
J_{\rm pol}
=
\frac{P^{n+1}-P^n}{\Delta t},
$

so the continuity identity follows from using the same divergence operator.

Free current is restricted to actual interior open links and evolves free charge by

$
\rho_{\rm free}^{n+1}
=
\rho_{\rm free}^{n}
-
\Delta t\,\nabla_{\rm open}\cdot J_{\rm free}.
$

Six-gate charge exchange is then applied explicitly as a boundary process.

## 5. Open Hamiltonian evolution

The weak open Hamiltonian is

$
H
=
\frac12\langle E,E\rangle
+
\frac{\beta}{2}\langle d_1A,d_1A\rangle.
$

Evolution uses leapfrog dynamics with the combined open current

$
J_{\rm total}
=
J_{\rm pol}+J_{\rm free}.
$

Thus the field being time-evolved is now the same open field used by the Gauss constraint.

This corrects the earlier v0.1 integration defect in which open Gauss diagnostics were computed from a separate static solution while the evolved gauge field still used periodic wraparound links.

## 6. Longitudinal Gauss projection

After the dynamical update, the engine computes

$
R_G
=
\nabla_{\rm open}\cdot E
+
b_{\partial V}
-
\rho_E.
$

It then solves for the minimum-energy longitudinal correction $\delta E$ satisfying

$
\nabla_{\rm open}\cdot\delta E=-R_G.
$

Only the longitudinal component is corrected.

The transverse radiative component generated by Hamiltonian evolution is retained.

This is the discrete analogue of a Helmholtz decomposition.

## 7. Topological magnetic diagnostics

Compact winding is evaluated on the same open plaquette complex.

For each face,

$
F_{\rm raw}
=
\bar F+2\pi n,
\qquad
n\in\mathbb Z.
$

The oriented divergence of face winding across each interior cube produces an integer compact magnetic defect.

Thus the topological diagnostic no longer depends on a hidden periodic gauge field when the engine is running in open mode.

## 8. Boundary accounting

Charge inflow and outward electric field flux remain distinct quantities.

The source bookkeeping variable uses positive sign for charge entering the domain.

The Gauss solver requires outward electric field flux satisfying total enclosed charge.

The current adapter uses observed gate activity only as relative weighting among the six outward field-flux faces. This weighting remains a modeling convention and is not yet derived from nested micro-to-macro dynamics.

## 9. Legacy periodic mode

The old periodic implementation remains available with

`boundary_mode="periodic"`

for comparison and regression testing.

It is no longer the default physical extension.
