# E8 Radial Degree Audit v0.1

## Result

The repository does not currently contain an independent scalar that can be
reused as an E8 radial amplitude without duplicating another degree of freedom.

## Existing amplitudes are already committed

### Matter amplitude

The matter amplitude already controls the radial matter mode, localized
structures, and matter energy.

Using it again as an E8 radius would identify matter amplitude with E8 Cartan
radius without a derivation.

### Port circulation amplitude

The port amplitude already determines Vesica, Tree, and adjacent-scale current
strength.

It is therefore not free to become an E8 radial variable.

### Nested oscillatory amplitude

The nested hierarchy amplitude already belongs to polarity and scale dynamics.

Reusing it would merge two previously distinct sectors.

### Neutral content scalar

The neutral content scalar already has a field equation, continuity role, and
matter coupling.

It is not an unused amplitude slot.

### Scale level

Scale level is an address/hierarchy coordinate. It is discrete and structural,
not a continuous E8 Cartan radius.

## Consequence

A genuinely variable E8 radius would require a new independently motivated
state variable.

That is a significant physical extension, not a harmless relabeling.

The repository therefore does not add such a variable at this checkpoint.
