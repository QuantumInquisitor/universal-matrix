# Omniverse Design Questions v0.1

## Purpose

This document treats the Universal Matrix as a candidate generative architecture and asks what is still required for it to correspond to the measurable universe.

The "creator" framing is used as a design metaphor only. The goal is not to assume the model is physically true, but to identify the missing laws that would have to be specified, derived, or falsified.

The questions are ordered from deepest foundations to emergent real-world observables.

---

## I. Ontology: what actually exists?

### 1. What is the primitive state?

Is the complete local state only

\[
(n,\sigma,\phi,A)
\]

or does a physically complete state also require:

- gauge links,
- conjugate momenta,
- scale index,
- boundary orientation,
- topological sector,
- matter species,
- information/entropy variables?

A real theory needs one explicit state space from which every later observable is derived.

### 2. What is physically real versus bookkeeping?

For each quantity, decide whether it is:

- fundamental,
- emergent,
- gauge redundancy,
- coordinate choice,
- numerical convenience.

In particular:

\[
n,\sigma,\phi,A,\theta,E,F,\ell,k,B_6
\]

cannot all automatically be independent physical observables.

### 3. Is the 108-state core local, global, or repeated?

Does one physical "cell" contain a copy of \(\mathbb Z_{108}\), or is the whole universe one 108-state core?

If repeated, what is the adjacency law between neighboring copies?

If global, how does macroscopic spatial locality emerge?

## II. Space and geometry

### 4. Why exactly three macroscopic spatial dimensions?

The six boundary orientations naturally support

\[
\{\pm X,\pm Y,\pm Z\}.
\]

But the model still needs a reason that these become three large physical dimensions rather than merely three labels.

What mechanism suppresses or internalizes all other state directions?

### 5. What defines physical distance?

A physical metric must determine a measurable interval.

Is distance determined by:

- graph distance,
- number of open links,
- accumulated phase,
- scale-layer ratio,
- field energy,
- a derived metric tensor,
- something else?

Without this, the lattice spacing \(a\) remains arbitrary.

### 6. Is space fundamentally discrete?

If yes, what is the smallest physical separation?

If no, what refinement or renormalization procedure sends the discrete architecture toward a continuum?

### 7. What creates isotropy?

The cubic open adapter picks three axes.

Why should long-distance observations become rotationally invariant?

The model needs either:

- exact microscopic symmetry,
- emergent isotropy,
- randomized orientation averaging,
- a renormalization argument.

### 8. What defines curvature if General Relativity is not primitive?

If gravity is to emerge rather than be inserted, what quantity replaces spacetime curvature?

Candidate possibilities include gradients of:

- phase,
- routing density,
- scale factor,
- gauge energy,
- information density,
- effective refractive structure.

A specific mathematical object is required.

\[
(\phi_x,\Pi_x)
\]

\[

=
\sum_x\frac{\Pi_x^2}{2I}
+

\sum_{\langle xy\rangle}
\left[
1-\cos\left(\phi_y-\phi_x+\theta_{xy}\right)

### What is now answered

**Locality:** immediate forces are confined to the six nearest neighbors.

**Conservative exchange:** link forces are equal and opposite, giving

\[
\frac{d}{dt}\sum_x\Pi_x=0.
\]

**Gauge transport:** the interaction depends only on the invariant combination

\[
\phi_y-\phi_x+\theta_{xy}.
\]

**Wave limit:** for small gradients,

\[
I\ddot\phi
=
\kappa\Delta_{\rm lat}\phi.
\]

**Dimensionless causal scale:**

\[
c_{\rm lat}
=
\sqrt{\kappa/I}.
\]

gauge-covariant sine of the effective phases.

change. This is now treated as a double-counting error.
